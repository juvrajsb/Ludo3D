# Third-Party Assets & Attribution

This project is an open-source, non-commercial software engineering project developed at Politecnico di Milano.

The following third-party assets, libraries, and resources are utilized in this repository:

---

### 1. Framework & Core Libraries
- **[LibGDX](https://libgdx.com/)**: Licensed under the [Apache License 2.0](https://www.apache.org/licenses/LICENSE-2.0).
  - Used for 3D OpenGL rendering, desktop launcher integration (LWJGL3), input handling, and math/vector utilities.

### 2. UI Skin & Fonts
- **[LibGDX Scene2D Default UI Skin](https://github.com/libgdx/libgdx/wiki/Skin)** (`assets/ui/uiskin.*`):
  - Created by Badlogic Games / LibGDX contributors.
  - Licensed under the [Apache License 2.0](https://www.apache.org/licenses/LICENSE-2.0).
- **Droid Sans Bitmap Font** (`assets/ui/default.*`):
  - Standard font packaged with LibGDX tests and skins.
  - Licensed under the [Apache License 2.0](https://www.apache.org/licenses/LICENSE-2.0).

### 3. 3D Models & Textures
- **3D Models** (`assets/models/pawn.g3db`, `assets/models/dice.g3db`, `assets/models/table.g3db`):
  - Modeled and converted to LibGDX G3DB format using Blender and `fbx-conv`.
- **PBR Textures** (`assets/models/textures/` and `assets/models/wood.jpg`):
  - Surface texture maps (Carpet, Marble, Wood) sourced from royalty-free, public domain CC0 texture libraries (such as [ambientCG](https://ambientcg.com/) and [Poly Haven](https://polyhaven.com/)).
  - Licensed under [Creative Commons CC0 1.0 Universal](https://creativecommons.org/publicdomain/zero/1.0/).

### 4. Environment & Skybox
- **Skybox Cubemap** (`assets/images/background_*.jpg`):
  - 6-sided cubemap environment textures utilized for 3D background rendering.
- **Board Graphic & Icons** (`assets/images/board.png`, `assets/images/icon.svg`):
  - Original vector artwork generated using Inkscape.
